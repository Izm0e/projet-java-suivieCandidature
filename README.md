# Application de suivie de Candidature

Permet de stocker le status de candidature à des entreprises.

## Fonctionnalités

- Possibilité d'ajouter une entreprise (nom de l'entreprise, le numéro de téléphone, l'addresse email).
- Possibilité de supprimer l'entreprise sélectionnée dans la liste.
- Possibilité de sauvegarder son avancement.
- Possibilité de changer le statut d'une candidature (Valider, En attente, Refusé).

## Lancement de l'application

Avec une interface : 
- Ouvrez le dossier du projet puis ouvrez le dossier "dist". 
- Enfin exécutez "RechercheEntrepriseV1.jar".

Avec une console : 
- Ouvrez le cmd sur le dossier du projet :
        - clique droit sur le dossier du projet.
        - "Ouvrir dans le Terminal"
- Puis exécutez la commande : "java -jar ./dist/RechercheEntrepriseV1.jar"
